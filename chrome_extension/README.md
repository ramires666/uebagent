# Local Browser MCP Chrome extension

Load this folder as an unpacked extension from `chrome://extensions` with Developer mode enabled. Pair it with the local service from the popup using the short lived pairing code issued by the service. The default service origin is `http://localhost:8080`; custom origins must use HTTP on `localhost` or `127.0.0.1` with a valid port.

The extension uses the Chrome Tabs, Cookies, Storage, and Alarms APIs. Its manifest grants access to the two loopback service hosts and declares `https://*/*` only as an optional permission pattern. It does not request cookie access until the web panel selects sites. The popup then lists the exact HTTPS origins and asks Chrome for those host permissions after the operator clicks **Grant selected site access**.

The service worker connects to `/api/v1/extension/channel`, authenticates in the first WebSocket message, sends heartbeats every 20 seconds while connected, and uses a Chrome alarm to recover after MV3 worker suspension or a dropped connection. It accepts only `open_sites`, `cookie_catalog`, and `cookie_export` jobs. Inputs and outputs are capped at 1 MiB. Catalog data is held in `chrome.storage.local` for at most ten minutes and contains no cookie values. Cookie values are read again immediately before export and only for selected catalog identities whose sites remain open in the same cookie store.

Cookie domains are queried for the selected host and parent candidates down to the registrable domain, then filtered by exact `hostOnly` or domain-cookie boundaries. The popup requests exact host permissions for those candidates, without a subdomain wildcard; granting a parent nevertheless permits Chrome API access to that parent beyond the selected host. For example, selecting `gemini.google.com` can request access to `google.com`, which also affects the scope of Chrome's permission for Google services. An isolated Chromium test confirmed that a parent-domain cookie is omitted with only the child permission and is visible when the exact parent permission is also granted. The bundled Public Suffix List contains ICANN and private rules and needs periodic updates (see [PSL provenance](PSL-PROVENANCE.md)). Partitioned cookies are unsupported and are never exported; Chrome may omit them entirely from the catalog.

No content scripts or webpage messaging are declared. The extension does not read Chrome profile files, use the debugger/CDP, or persist cookie values.
