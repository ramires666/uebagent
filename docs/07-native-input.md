# Experimental container X11 input

This backend is not connected to the worker and is not enabled by default. Use only with an isolated Xvfb display inside the browser container, never with a shared or host display. The production integration must obtain the browser-specific process ID independently; the worker PID is not a suitable identity.

`NativePage(page, expected_pid, check_epoch)` exposes `evaluate`, `locator`, `mouse`, and `keyboard`; `await aclose()` releases tracked input. The caller must hold the existing worker input lock across each entire action, including all drag steps, and provide a synchronous epoch check. Restart the isolated browser on an unknown release or clipboard-cleanup outcome. One context and one visible owned Camoufox window are required.

Page screenshots are compared in memory against X11 pixels using three independent, high-variance patches; at least two unique matches must agree, and the entire viewport must fit inside the visible browser and screen. Blank, repeated, dynamic, obscured or insufficiently detailed pages can fail closed. Input uses X11, never Playwright input. On drag, calibration is retained only while the button is held; window identity, geometry, focus and epoch are checked at each step. The release helper is a killable subprocess with a 0.4-second limit; a failure is an unknown outcome. Clipboard text is served by a private short-lived X11 selection owner; a text SelectionRequest is confirmed before it exits. This confirms an X11 request, not that an application accepted or retained the text. No text or screenshot is logged or written to a file. Wheel movement is quantized to X11 detents, not pixel-accurate.

Test: `docker build -f deploy/Dockerfile.browser-native -t uebagent-native-test .`, followed by `docker run --rm --network none --memory 2g --cpus 2 --entrypoint sh uebagent-native-test -c 'Xvfb :99 -screen 0 1440x1000x24 -nolisten tcp & export DISPLAY=:99 PYTHONPATH=/app:/app/src NATIVE_INPUT_INTEGRATION=1; sleep 2; timeout 90 python /tmp/test_native_input.py'`. The test uses a temporary profile, one page, Camoufox `window=(1440,1000)` and a 1440x900 viewport. The integration test exercised native click, ASCII/Unicode, clipboard cleanup, keyboard, ten drag steps, stale epoch, cancellation release, scroll, and blank-page rejection. The helper timeout is separately unit-tested.

Production readiness still requires independent review and integration testing: trustworthy browser PID acquisition, private display enforcement, pixel format and occlusion assumptions, cancellation under a stalled X server, repeated clipboard selection and page navigation, and the worker's precise timeout/error mapping. X11/PyAutoGUI do not guarantee humanization or undetectability.
